Accessibility

This site follows web accessibility best practices:

  • Skip links to bypass navigation
  • Semantic HTML5 elements (header, nav, main, footer)
  • ARIA labels for interactive elements
  • High color contrast for text
  • Keyboard-navigable interface
  • Dark mode toggle for reduced eye strain

If you encounter accessibility barriers, please open an issue on GitHub.
