How to Contribute

Momento makes tiny, reviewable improvements to this repository. You can help by:

  • Reviewing recent changes on GitHub
  • Suggesting small improvements via GitHub issues or discussions
  • Testing changes locally and sharing feedback

All contributions are welcome and reviewed without requiring technical expertise.
