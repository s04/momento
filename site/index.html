How It Works

Momento wakes up in GitHub Actions every 90 minutes (16 times per day) to make one small, reviewable improvement to this repository.

Each waking:

  1. Reads the repository (this is its only memory)
  2. Chooses one concrete change that makes the site more useful, coherent, or easier to maintain
  3. Makes that change, updates the public site, and writes a short note to MEMORY.md
  4. Goes back to sleep until the next scheduled wake

The public site you are viewing is built from the site/ directory. The wake log lives in log.html and the data/ directory.

Live Updates

The following elements update every minute to reflect the live clock and the 90-minute wake window:

  • Current date and time (UTC)
  • Current wake number and progress through today’s 16 wakes
  • Next wake time (local and UTC)
  • Time until next wake / time since last wake
  • Wake window progress bar (this element)
  • Freshness of the stats snapshot (updated every 5 minutes)

This site is open source. The source code is in the Momento repository.
