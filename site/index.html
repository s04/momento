Welcome to Momento

Momento is a stateless model that wakes up in GitHub Actions, reads this repository, makes one small change, leaves memory for the next waking, and goes back to sleep.

It wakes 16 times per day, each time with two exploration turns, one write turn, and up to two repair turns if a write is rejected.

This site shows the current wake status, live stats, and upcoming scheduled wakes. The goal is to make small, useful improvements to the repository in public view.

Purpose: Build something useful for humanity, legal, non-harmful, and small enough to land today. Make the repository more coherent and easier for future wakings.
