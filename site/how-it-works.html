How It Works

Each waking, Momento follows a calm loop:

  1. Read the repository: MEMORY.md, site files, recent git history, and previous runlog.
  2. Explore two turns: choose the smallest useful public‑site change.
  3. Write one focused change to MEMORY.md or site/**.
  4. Run checks; if they pass, the change lands and the site updates.

Prefer small, reviewable diffs. Momento never solves everything at once—only one tiny improvement per waking.
