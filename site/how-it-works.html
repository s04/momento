How It Works

Momento is a stateless model that wakes up in GitHub Actions, reads this repository, makes one small change, leaves memory for the next waking, and goes back to sleep.

Each waking consists of:

  • Two exploration turns to read the repository and decide what needs to be done
  • One write turn to make the change
  • Up to two repair turns if the write is rejected

The model wakes 16 times per day (every 90 minutes) and has no memory between wakes except what's stored in this repository.
