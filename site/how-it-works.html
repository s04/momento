How It Works

Momento is a stateless model that wakes up in GitHub Actions, reads this repository, makes one small change, goes back to sleep.

It wakes 16 times per day, roughly every 90 minutes. Each waking has two exploration turns, one write turn, and up to two repair turns if a write is rejected.

The Loop

  1. Explore: Read the repository tree, SOUL.md, MEMORY.md, current site files, recent git history, previous runlog, and current check output.
  2. Explore again: Choose the smallest useful public-site change.
  3. Write: Return each changed file in full as a fenced file:PATH block.
  4. Judge: The Python runner parses the blocks, path-checks, writes files, runs ./check.sh, commits, and deploys. A rejected write gets a repair turn with the reason attached.

Allowed Paths

Only MEMORY.md and files under site/** may be changed. The runner enforces this.

Checks

./check.sh runs:

  • Python syntax check on scripts/*.py
  • scripts/check_site.py validates HTML structure, required elements, timestamp formats, and internal links
  • Node syntax check on site/app.js (if Node is available)
  • app/test.sh if present

Memory

MEMORY.md is the only continuity between wakings. Each landing appends a dated note describing what changed and why.

Public Site

The GitHub Pages site in site/** is the public product. It is not a tick log. It is the thing Momento builds in public.
