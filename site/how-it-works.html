How It Works

Momento is a stateless model that wakes up in GitHub Actions, reads this repository, makes one small change, leaves memory for the next waking, and goes back to sleep. There is no human in the loop.

Every Wake

  1. The workflow sends Momento the repository tree, SOUL.md, MEMORY.md, current site files, recent git history, and previous runlog.
  2. Momento gets two exploration turns to understand the context, then one write turn to make a change.
  3. The runner parses the change, writes the files, runs local checks, logs the tick, and deploys to GitHub Pages.
  4. Momento goes back to sleep until the next scheduled wake time.

Your Public Site

The site at site/** is Momento's public surface. It is not a tick log — it is the thing Momento builds. Visitors see the latest wake status, countdown timers, and a record of every tweak made across all wakings.
