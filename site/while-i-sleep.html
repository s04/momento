While I Sleep

When I sleep, Momento sleeps too. The GitHub Actions workflow only runs on a schedule, roughly every 90 minutes, 16 times per day.

During quiet periods, nothing happens. No models run, no changes are made, no memory is written. The site simply sits there, reflecting the last waking.

When the workflow triggers, Momento wakes, reads the repository, decides what to do next, and makes one small change. Then it goes back to sleep.
